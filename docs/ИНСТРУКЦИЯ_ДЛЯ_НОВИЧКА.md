# Как запустить AvatarStudio — инструкция для новичка

Ничего программировать не нужно. Нужно: установить одну программу,
скачать один архив и ввести одну команду. По времени — 20–30 минут,
большая часть — ожидание установки и сборки.

---

## Шаг 1. Установите Docker Desktop (одна программа)

Docker — это программа, которая запускает наше приложение «в коробке»
со всем необходимым внутри. Ничего другого ставить не придётся.

1. Откройте сайт: **https://www.docker.com/products/docker-desktop/**
2. Нажмите большую кнопку **Download Docker Desktop** (сайт сам
   определит вашу систему — Windows или Mac).
3. Запустите скачанный файл и жмите «Далее/OK», ничего не меняя.
   - На Windows установщик может попросить включить **WSL 2** —
     соглашайтесь и перезагрузите компьютер, если попросит.
4. После установки **запустите Docker Desktop** (иконка кита 🐳).
   Дождитесь, пока в левом нижнем углу окна загорится зелёный
   индикатор **Engine running**. Регистрироваться в Docker не
   обязательно — окно входа можно закрыть/пропустить (Skip).

Docker Desktop должен быть **запущен** каждый раз, когда вы
запускаете приложение.

---

## Шаг 2. Скачайте приложение (один архив)

1. Откройте эту ссылку — архив скачается сам:

   **https://github.com/Arsxur1/humming-vue-info/archive/refs/heads/claude/stage-0-setup-qnpv9l.zip**

2. Найдите скачанный файл (обычно папка «Загрузки») и **распакуйте** его:
   - Windows: правой кнопкой → «Извлечь всё…» → «Извлечь».
   - Mac: просто двойной щелчок.
3. Получится папка с длинным именем вроде
   `humming-vue-info-claude-stage-0-setup-qnpv9l`. Запомните, где она.

---

## Шаг 3. Откройте терминал В ЭТОЙ ПАПКЕ

Терминал — это чёрное окно, куда вводят команды. Открыть его сразу
в нужной папке проще всего так:

**Windows:**
1. Откройте распакованную папку в Проводнике (зайдите ВНУТРЬ неё —
   вы должны видеть файлы `Dockerfile`, `docker-compose.yml`).
2. Нажмите на адресную строку сверху (где путь к папке), сотрите всё,
   напишите `cmd` и нажмите Enter. Откроется чёрное окно — это оно.

**Mac:**
1. Откройте распакованную папку в Finder.
2. Правой кнопкой по папке → «Службы» → «Новый терминал по адресу папки».
   (Если такого пункта нет: откройте Терминал из Launchpad, напишите
   `cd `, перетащите папку мышкой прямо в окно терминала и нажмите Enter.)

---

## Шаг 4. Введите одну команду

Скопируйте эту строку, вставьте в терминал и нажмите Enter:

```
docker compose --profile app up --build
```

Дальше просто ждите. **Первый запуск занимает 5–15 минут** — Docker
скачивает и собирает всё необходимое, в окне будет бежать много
текста. Это нормально. Когда бег текста успокоится и появятся строки
вроде `listening on http://localhost:3001` и `Local: http://localhost:5173`
— всё готово.

Окно терминала **не закрывайте** — пока оно открыто, приложение работает.

---

## Шаг 5. Откройте приложение

В обычном браузере (Chrome и т.п.) откройте адрес:

**http://localhost:5173**

Что делать дальше:
1. Нажмите «Нет аккаунта? Регистрация» → придумайте имя, любой e-mail
   (письма никуда не отправляются) и пароль от 8 символов.
2. Выберите один из готовых шаблонов внизу страницы (например
   «Онбординг: первый день»), заполните поля → «Создать проект».
3. Откроется редактор: слева сцены, в центре холст, внизу текст сцены
   с кнопками разметки (пауза, жест, ударение…).
4. Нажмите **«Рендер»** справа вверху → подождите несколько секунд →
   появится готовое видео, его можно посмотреть и скачать.

Важно понимать: сейчас включён **тестовый режим** — в видео вместо
живого человека серая плашка «АВАТАР» и тишина вместо голоса, но с
настоящими субтитрами. Так и задумано: живой голос и аватар подключаются
позже, когда появятся ключи от платных сервисов (ElevenLabs, HeyGen и т.п.).

---

## Как выключить и включить снова

- **Выключить:** в окне терминала нажмите `Ctrl+C` (на Mac тоже
  Control+C), подождите пару секунд. Можно закрыть окно.
- **Включить снова:** шаг 3 (терминал в папке) + команда
  `docker compose --profile app up` (уже без `--build` — запустится
  за минуту). Docker Desktop при этом должен быть запущен.
- Все ваши проекты и видео сохраняются между запусками.

---

## Если что-то пошло не так

Три самые частые ситуации:

1. **«docker: command not found» или «не является командой»** —
   Docker Desktop не установлен или компьютер не перезагружали после
   установки. Вернитесь к шагу 1.
2. **«Cannot connect to the Docker daemon» / «error during connect»** —
   Docker Desktop установлен, но не запущен. Запустите его (иконка
   кита) и дождитесь зелёного индикатора, потом повторите команду.
3. **«no configuration file provided» / «docker-compose.yml not found»** —
   терминал открыт не в той папке. Вернитесь к шагу 3: терминал должен
   быть открыт внутри папки, где лежит файл `docker-compose.yml`.

Если ошибка другая — **выделите весь текст в терминале, скопируйте
и пришлите** (или сделайте скриншот). По тексту ошибки я скажу, что
именно исправить.
