# Legacy HFO content

Файлы в этом каталоге **не относятся к AvatarStudio**. Это материалы более
раннего проекта — обучающего приложения по высокочастотной осцилляторной
вентиляции (Humming Vue HFO): HTML-прототипы, JSX-компоненты, строки
локализации, изображения и PDF-статьи.

Они перенесены сюда из корня репозитория при переходе на AvatarStudio, чтобы
не смешиваться с исходниками платформы. К сборке, линтингу и тестам монорепо
не подключены. Удалить можно в любой момент без влияния на AvatarStudio.
